## 🥥 О проекте

**Coco IDE** — интегрированная среда разработки для **CDM-8**, созданная для простого и удобного процесса разработки.

Она объединяет основные инструменты, необходимые для работы с программами CDM-8, в одном понятном интерфейсе.

## ✨ Возможности

- ✏️ Редактирование исходного кода
- ▶️ Запуск программ
- 🐞 Инструменты отладки
- 💻 Простой и понятный интерфейс
- 🪟 Поддержка Windows
- 🍎 Поддержка macOS

## 🛠 Установка

### Windows

1. Откройте страницу последнего релиза.
2. Скачайте версию **Coco IDE для Windows**.
3. Запустите скачанный файл.

### macOS

1. Откройте страницу последнего релиза.
2. Скачайте подходящую версию **Coco IDE для macOS**.
3. Распакуйте архив.
4. Перенесите приложение CocoIDE в папку **Программы** (`Applications`).

Если macOS блокирует запуск загруженного приложения и вы скачали его из официального репозитория Coco IDE, откройте **Терминал** и выполните:

#### Apple Silicon

```bash
xattr -dr com.apple.quarantine "/Applications/CocoIDE Apple Silicon.app"
